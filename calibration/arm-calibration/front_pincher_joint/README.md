## What is fitted

`joint.py` fits front `K/D`, one stationary-block `T_F_W`, rigid after-M5 `T_G_M`, and one latent `T_W_G` per eligible bracket. `T_A_B` maps B coordinates into A; translations are metres; F/G are OpenCV optical frames, W the ChArUco print frame, M the 15 mm black ID68 square frame. No nominal FK, jog angle, exact camera height, wrist station or tape dimension enters the objective.

Every training bracket contributes the actual two F floor images, two F marker images, and two G board images. PnP transforms initialize the fit, never become additional independent observations. G poses are nuisance variables constrained by their board pixels. Each image's residual vector is divided by √corner count, with soft-L1 scale 0.5. This gives equal image weight, not a detector-noise covariance model; duplicate images are not independent poses. Full, untrimmed residuals are reported separately by camera/target.

Five nested lens models are compared: frozen front optics, shared focal, focal+cy, focal+cy+k1, and fx/fy/cx/cy/k1/k2. k2 stays at the old front value in the smaller models; tangential distortion is zero. Four training-only leave-whole-pose-group-out folds keep both nominal 250/55/0 approach repeats together. The simplest model within 10% of the best combined floor/marker RMS is selected, provided floor CV is no more than 110% of baseline. Numerical bounds and flags are retained. Selection requires the full training fit **and every CV fold fit** to converge, avoid all bounds, and put every fitted F-floor, F-marker and G-floor corner at strictly positive optical depth. CV evaluation targets must also have positive depth. `models-progress.json` / `models.json` retain scoped `invalid_reasons` (`success`, `bound_hits`, `positive_depth`); one invalid fold excludes the whole model rather than dropping that fold. If no model is eligible, the run fails explicitly before freezing a selection.

`protocol.json` and then `selection-frozen.json` are written before final evaluation. All F pixels of the three final brackets are withheld; their G-only board fit supplies observed pose inputs. K, T_F_W and T_G_M stay frozen for that evaluation. **The prior analysis already inspected these retained holdouts: this is a declared exploratory reanalysis, not new independent prospective validation.** Marker PnP/branch disagreements are diagnostics, not external ground-truth pose accuracy. G-only pose inference rejects optimizer nonconvergence (including the bracket ID and optimizer message) and nonpositive G-board depth with `ValueError`; held-out evaluation and fixed-G conditional fitting propagate that error and abort instead of reporting an apparently successful pose or RMS.

The eight eligible / two rejected brackets and original stationarity policy are unchanged. The marker's 12.78° pilot-derived orientation threshold reflects planar-pose noise, not 1° mechanical accuracy. Shared-stream exposures are not simultaneous and have no exact exposure timestamps.

## Diagnostics and geometry

- `conditional-versus-joint.json`: explicitly frozen G-only poses versus latent-G pixel fitting.
- `identifiability.json`: scaled nuisance-projected numerical Jacobian, weakest vectors, reoptimized focal/cy profiles, displaced multistarts. Local rank is not physical certification.
- `uncertainty.json`: whole-bracket bootstrap jointly propagated with existing G-lens whole-pose bootstrap draws, convergence counts, sampled supports, full fits and held-out predictions. Excludes shared print/planarity/detector/timing/remount systematics.
- `historical-floor-validation.json`: frozen chosen K tested on prior-session floor frames, fitting a fresh T_F_W per documented A/B/D stationary block from training images. No historical marker mounting transform is assumed shared.
- `geometry.json`: real G corner-space pure-joint axes refitted under the validated G lens; L1 at a declared common transverse station; candidate front registration of shoulder; front-only marker elbow/roll crosschecks; effective elbow→optical/marker vectors, explicit anatomical nulls.
- `coverage-and-acquisition.json`: observed support plus **design-only** information calculations on a declared optical-space grid. Arbitrary spatial targets are not asserted mechanically reachable.
- `achieved-pose-acquisition-design.json`: ranks only previously achieved G poses for a future F/G/G/F counterpart, excluding equivalent already paired poses and the two missing-ID68 rejects. Front visibility remains a prediction, not an acquired observation.

## Preservation and tests

The CLI requires an explicit **not-yet-existing output directory**; choose a fresh scratch name for each run (the example path must not already exist). It resolves symlinks before rejecting preserved source-directory overlap, descendants or ancestors, and also protects its code and retained `20261015-front-pincher-joint` results directory. Existing directories are refused even if empty; retained results cannot be regenerated in place. The resolved output parent is opened component-by-component from a root descriptor with directory/no-follow flags, inode identity checks and preserved-source-root rejection. Missing parents and the fresh output leaf are created relative to those descriptors; the output is opened relative to its validated parent and rejected if its inode changed or it is nonempty. All generated files are JSON and pass through one writer: exclusively created no-follow temporary files are atomically replaced relative to the held output descriptor. Destination symlinks/hardlinks are never truncated, and swapping an ancestor to a symlink before parent/output opening or swapping the output path after opening cannot redirect writes into evidence. This protects path/link redirection, not arbitrary concurrent relocation of already-open directories by another process. On failure, old evidence is left intact and partial new output is retained for inspection; use another fresh name to retry. No legacy archive-writing CLI is invoked. Tests use disposable directories under Hermes scratch; retained results stay read-only in the repository.

`archive-before-sha256.json` records preserved inputs; `software-and-code.json` records versions and code/input hashes. `archive-verification.json` verifies before/after sources, the earlier 410-file baseline, and original 92-image manifest. Tests exercise transform composition, source/ancestor/symlink refusal, actual training-only pixel fitting, independence of held-out F pixels from G pose input, fixed-G conditional fitting, PSD design information, achieved-pose design, and an end-to-end real-data CLI run. The original eight tests plus seven regression tests pass (15 total). Added regressions cover preexisting symlink/hardlink outputs, link/directory-swap races and ancestor swaps immediately before parent/output descriptor opening with protected scratch bytes unchanged, invalid full/fold fits and CV evaluation depth, real-solver G-only nonconvergence propagation, a converged behind-camera G-only branch, and all three target depths. The end-to-end scratch run still selects `fcyk1`, reproducing marker RMS 5.497539 px and pitch-bracket RMS 9.130255 px; all retained full/CV fit validity flags remain valid. No robot, camera, service, Docker, network, production edits or commits.
