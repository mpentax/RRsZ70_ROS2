# Copied display meshes

`cad_body.stl` is the white static shell in the base_link frame. Colored display meshes on the same link are the bumper, wheels, mops, vacuum spinners and lens tower. The shoulder housing is `cad_shoulder_mount.stl`, fixed on the body at the joint, not baked onto the rotating upper arm. Arm links stay in their own frames. None of these load the original model.
